# Nomad NZ 开发规范

## 📋 项目简介

Nomad NZ 是一个轻量露营 App，核心功能：
1. 营地智能推荐
2. 一键生成行程
3. 露营档案（去过/想去）
4. 轻社区（图片+文案分享）

## 🛠️ 技术栈

- **Next.js 14** App Router
- **Supabase** Auth + Postgres
- **TailwindCSS** + **Shadcn/ui**
- **OpenAI API** for recommendations
- **TypeScript** 全局统一

## 📁 项目结构

```
/src
 ├─ app
 │   ├─ page.tsx                # 首页（营地推荐）
 │   ├─ explore/page.tsx        # 发现营地
 │   ├─ trip/page.tsx           # 生成行程
 │   ├─ community/page.tsx      # 社区
 │   ├─ profile/page.tsx        # 我的
 │   └─ api
 │        ├─ recommend/route.ts # 营地推荐接口
 │        └─ trip/route.ts      # 行程生成接口
 ├─ data/camps.json             # 初始营地数据
 ├─ components                  # UI 组件
 ├─ lib                         # 工具库、AI模块、Supabase
 └─ types                       # TypeScript 类型定义
```

## ✅ 开发准则

1. **所有返回的代码必须可执行、完整、带 import**
2. **不要生成伪代码或省略代码**
3. **文件路径必须正确，遵守 /src/app/... 的结构**
4. **优先写函数式组件**
5. **所有 API 返回 JSON，不返回 HTML**
6. **任何用户输入必须先校验**
7. **生成 UI 时必须使用 TailwindCSS**
8. **能复用组件就复用（/src/components）**

## 📝 代码生成规范

### 写代码时
- 严格按照项目结构生成
- 必须包含 import
- 不要写解释，除非要求
- 优先拆分成组件文件：`components/`

### 设计 API 时
必须返回：
- 完整的 `route.ts`
- 类型接口定义
- 参数校验

### 构建 UI 时
应该：
- 生成完整 `page.tsx` 文件
- 使用 `<Card>`、`<Button>` 等 shadcn 组件
- 使用 grid、flex 布局
- 保持界面简洁、轻松、有呼吸感

## 🎯 营地推荐算法

- **基础来源**：`data/camps.json`
- **推荐逻辑**：根据 location、days、budget、人数 匹配最相关营地
- **补充**：必要时调用 OpenAI 生成解释文本

## 🤖 AI Prompt 规范

所有 AI 调用必须使用以下格式：
```typescript
[
  { role: 'system', content: '...' },
  { role: 'user', content: '...' }
]
```

解释文案必须轻松、自然、旅行感。

## 🎨 设计原则

- **减少选择**：界面简洁，减少用户决策负担
- **一步到位**：输入需求 → 直接获得推荐
- **轻松舒适**：绿色主题，像森林一样舒服
- **专注核心**：不做多余功能，围绕"露营体验"

## 📌 注意事项

- 确保所有输出有助于 MVP 快速上线
- 不要过度抽象
- 保持代码简洁、可维护
- 优先完成核心功能，再考虑扩展
